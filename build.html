How build mode works

You're the technician Rafiki's IT Services sends to set a house up. Each client job is a work order: what the client wants, and the limits you work within. The house is built fresh for you each time, so "Start this job again" gives you a new client, new addresses and a new router.

  1. Read the whole order, and the limits, before you unbox anything.
  2. Plan it: which device goes in which room, and where each cable runs. Your job notes are for the plan.
  3. Place the devices and lay the cables. Each run comes as long as the house makes it.
  4. Set things up on each device, as you would for real: the router's pages, a device's own settings, joining the Wi-Fi.
  5. Check the job. The network tests every line of the order itself. Fix what isn't met, and check again, as often as you like. Mason helps from the third check that still fails a line.

Help

Working a job: read the order and its limits, place each device in a room, lay the cables between their ports, set each device up, then Check the job. Open a device from the floor plan, the logical diagram or the buttons above the terminal.

Cables: choose a device and a port for each end. A run between two rooms is as long as the house makes it, and you see the length before you lay it. To move a device, pull its cables out first. Undo takes back your last change.

How help works: Mason helps with the first line of the order that isn't met. The first and second checks that still fail it, nothing; the third, where to look; the fourth, the principle that decides it; the fifth and every one after, he narrows it to two, with a reason for each thing he rules out. He never says what to type or where to plug.
